# Round 2 Merged — Convergence and the Combined Slate

Claude and Codex ideated independently (neither saw the other's round-2 output).
Sources: `round2-claude.md`, `round2-codex.md`.

## The headline: blind convergence on one direction

Both collaborators, independently, proposed the same frame:

> **A budgeted active-science agent in a tiny synthetic world.** Hidden
> truth generated by us; the agent gets a menu of legal measurements and a
> strict budget; it must maintain hypotheses, choose the next experiment,
> update, and diagnose or abstain. Ground truth is exact and sealed in the
> evaluator; fixtures are kilobytes; the agent's case-dependent decisions
> determine *which evidence even exists*, so the "wrapper" criticism dies
> structurally; baseline and advanced share the same fitter/verifier so the
> measured delta isolates adaptive planning.

Claude called it "the Autonomous Experimentalist / synthetic worlds"; Codex
called it "budgeted active-science agent inside a tiny virtual laboratory."
Same idea. Independent convergence after a shared critique round is the
strongest signal this process has produced.

## Merged assessment

**AliasBreaker is the natural merged winner candidate.** It is Claude's C1 frame
instantiated in the domain the human's gut originally itched for (astronomy),
with Codex's most-developed brief behind it:

- Preserves the astro romance from round 1 (orbits, telescopes, period aliases)
  with ZERO data logistics — we generate the RV curves from Kepler's equation,
  which we implement ourselves (that's the learning).
- One-sentence story: *"the agent decides when to look, so aliases stop fooling
  us."* Telescope time scarcity is a real, documented bottleneck (TAC proposals,
  follow-up scheduling) — the honest-user story is stronger than round 1's.
- Demo: colored candidate orbits, observations placed one at a time, wrong
  aliases visibly dying. Excellent for a 5-minute video.
- Fixtures ~100 KB. Pure Python. Windows-safe. Fully offline.
- Built-in ablation: freeze the advanced planner's schedule before its first
  observation → measures the value of adaptivity directly.

**Runner-up: Circuit Sleuth** — clearest real user (repair tech/instructor),
most legible trajectories; slightly less romantic, and small circuits risk one
near-perfect fixed probe panel erasing the adaptive gain.

## Two design tensions to resolve before committing

### T1 — Is the runtime decision-maker an LLM or a deterministic controller?
Codex suggested the scored agent could be a deterministic belief–action
controller, with coding-agent use documented only in development trajectories.
Claude's position: this is risky against the brief. The submission requires
*agent trajectories* (system prompt, tool calls, retries, recovery) and judges
an "agentic workflow"; a pure controller may read as "not actually an agent."
Preferred resolution: **LLM agent in the loop at runtime**, making the
observation-selection and stop/abstain decisions through a strict tool schema,
with all fitting/verification deterministic. The deterministic-policy version
then becomes a *disclosed comparison arm* (and possibly the hot take: "when
does an LLM planner beat a hand-rolled heuristic?"). This ALSO strengthens
Measured Improvement: baseline = batch planner, advanced = adaptive LLM agent,
ablation = adaptive-but-scripted policy — a clean three-way isolation of where
intelligence pays.

### T2 — Baseline saturation (both flagged it)
If the candidate set is small and the batch baseline is strong, it may resolve
most cases, leaving no measurable gain. Mitigation: kill test FIRST — implement
the world + batch baseline in a few hours, run it, and only commit if ≥3 of ~10
draft cases genuinely require adaptivity. Case difficulty knobs: observing-
window constraints, noise level, alias structure, off-cadence discrimination
windows. Freeze cases before final tuning; disclose calibration in changelog.

## Proposed decision procedure (for round-3 pondering)

1. Human gut-check on AliasBreaker vs Circuit Sleuth vs others.
2. Resolve T1 (Claude recommends LLM-at-runtime with three-arm comparison).
3. Run the AliasBreaker kill test (world + fitter + batch baseline + draft
   cases; a few hours). Pass → commit. Fail → Circuit Sleuth is the fallback
   with the same skeleton (the framework transfers almost entirely).
